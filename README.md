## 🚀 Proyectos Destacados

### 🏙️ [Mi Ciudad](https://github.com/lillystarfull)
> **Plataforma web de reporte ciudadanas y gestión pública municipal (Bello, Antioquia)**
- **Descripción:** Sistema integral para que los ciudadanos reporten incidencias de infraestructura y servicios públicos, permitiendo seguimiento en tiempo real y administración mediante roles (Ciudadanos, Funcionarios, Administradores).
- **Tecnologías:** PHP, SQL, HTML5, CSS3, JavaScript, Python (Análisis estadístico con Pandas/Seaborn).
- **Funcionalidades:** Mapeo de navegación, arquitectura modular, análisis descriptivo de datos de reportes por comuna y gestión de PQRS.

### 🤖 [GN Smart Chat](https://github.com/lillystarfull)
> **Solución de automatización e IA para PyMEs**
- **Descripción:** Modelo de negocio y arquitectura técnica para la implementación de agentes conversacionales inteligentes integrados a WhatsApp.
- **Tecnologías:** Python, APIs de IA, Automatización de Flujos.
- **Funcionalidades:** Atención al cliente 24/7, reducción de costos operativos y gestión automatizada de consultas.
